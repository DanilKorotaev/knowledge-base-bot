# Промпт для разработки

## Стиль кода

- Используйте type hints для всех функций
- Следуйте PEP 8
- Документируйте функции и классы docstrings
- Используйте логирование вместо print

## Структура

- Каждый модуль должен иметь `__init__.py`
- Используйте абстракции (интерфейсы) где возможно
- Разделяйте бизнес-логику (services) и обработчики (handlers)

## Тестирование

- Пишите тесты для новых функций
- Используйте моки для внешних зависимостей
- Тестируйте edge cases

## Обработка ошибок

- Всегда обрабатывайте исключения
- Логируйте ошибки с полным контекстом
- Возвращайте понятные сообщения пользователю
