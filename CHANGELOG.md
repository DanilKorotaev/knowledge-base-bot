# Changelog

Все значимые изменения в проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Added
- **Встроенные сессии Cursor CLI (`--resume`):**
  - Гибридный подход: собственные сессии БД + встроенные сессии Cursor CLI
  - Новый метод `CursorCLIService.create_chat()` для создания чатов через `cursor-agent create-chat`
  - Поле `cursor_chat_id` в таблице `sessions` (миграция для SQLite и PostgreSQL)
  - Автоматическое создание чата при первом запросе в сессии (lazy initialization)
  - Использование `--resume <chatId>` для продолжения диалога без передачи истории
  - Fallback на ручную передачу истории при ошибке `--resume`
  - Docker volume `cursor_chats` для персистентности чатов Cursor CLI
- Базовая структура проекта
- Конфигурация через переменные окружения
- Поддержка PostgreSQL и SQLite
- Обработчики команд и сообщений (заглушки)
- Сервисы для работы с Cursor CLI и OpenAI
- Документация и системные промпты
- Docker конфигурация
- Документация по Git Flow (docs/GIT_FLOW.md)
- Скрипты автоматизации Git Flow (scripts/git_flow_*.sh)
- Система задач (docs/todo.md, docs/completed.md)
- Инициализация Git репозитория согласно Git Flow
- **Система ограничения доступа к боту:**
  - Режимы доступа: открытый (`open`) и ограниченный (`restricted`)
  - Поля `is_allowed` и `is_admin` в таблице `users`
  - Middleware для проверки доступа перед обработкой запросов
  - Административное меню с интерактивными командами
  - Поддержка выбора пользователя через UI Telegram (KeyboardButtonRequestUsers)
  - Поддержка отправки контакта пользователя
  - Выбор пользователя из списка с пагинацией
  - Автоматическая инициализация администраторов из конфигурации
  - Логирование попыток доступа от неавторизованных пользователей

### Changed
- Обновлен `/start` для проверки доступа в режиме `restricted`
- Обновлен `/help` - административные команды не отображаются в справке
- Главное меню теперь показывает кнопку "⚙️ Админка" для администраторов
