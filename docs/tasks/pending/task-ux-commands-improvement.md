# Улучшение интерфейса команд

**Статус**: 📋 Запланировано  
**Приоритет**: 🟡 Средний  
**Категория**: Улучшения UX

## Описание

Улучшение интерфейса команд бота для более удобного взаимодействия с пользователем.

## Цели

1. Улучшить сообщения команд (более понятные и информативные)
2. Добавить подсказки и примеры использования
3. Улучшить обработку ошибок с понятными сообщениями
4. Добавить валидацию входных данных

## Задачи

- [ ] Улучшить сообщения команд (более понятные и информативные)
- [ ] Добавить подсказки и примеры использования для каждой команды
- [ ] Улучшить обработку ошибок с понятными сообщениями пользователю
- [ ] Добавить валидацию входных данных для команд
- [ ] Добавить прогресс-индикаторы для долгих операций
- [ ] Улучшить форматирование ответов (Markdown)

## Примеры улучшений

### Команда /new_query

**Было:**
```
✅ Начат новый запрос с контекстом базы знаний.
```

**Станет:**
```
✅ Начат новый запрос с контекстом базы знаний.

📝 Вы можете:
• Отправить текстовое сообщение
• Отправить голосовое сообщение
• Прикрепить файл или фото

💡 Примеры запросов:
• "Найди информацию о системе авторасходов"
• "Обнови документацию по проекту"
• "Создай заметку о встрече"
```

## Связанные файлы

- `handlers/commands.py` - обработчики команд
- `utils/message_helpers.py` - помощники для сообщений
