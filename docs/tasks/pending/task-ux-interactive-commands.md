# Интерактивный режим команд

**Статус**: 📋 Запланировано  
**Приоритет**: 🔴 Высокий  
**Категория**: Улучшения UX

## Описание

Реализация интерактивного режима работы с ботом через главное меню и кнопки вместо текстовых команд. Пользователь должен иметь возможность выполнять все действия через интуитивно понятный интерфейс без необходимости запоминать команды или искать справку.

## Цели

1. Реализовать главное меню с кнопками для основных действий
2. Заменить текстовые команды на интерактивные кнопки (Reply Keyboard)
3. Реализовать контекстные клавиатуры, которые меняются в зависимости от состояния
4. Реализовать inline-кнопки для быстрых действий и навигации
5. Обеспечить плавные переходы между состояниями интерфейса

## Технические детали

### Структура клавиатур

```python
# В handlers/keyboards.py

def get_main_keyboard() -> ReplyKeyboardMarkup:
    """Главная клавиатура"""
    keyboard = ReplyKeyboardMarkup(
        keyboard=[
            [
                KeyboardButton(text="📚 Новый запрос"),
                KeyboardButton(text="💬 Новый чат")
            ],
            [
                KeyboardButton(text="📋 Мои сессии"),
                KeyboardButton(text="📜 История")
            ],
            [
                KeyboardButton(text="🔄 Синхронизация"),
                KeyboardButton(text="❓ Помощь")
            ],
            [
                KeyboardButton(text="🏠 Главное меню")
            ]
        ],
        resize_keyboard=True
    )
    return keyboard

def get_sessions_keyboard(sessions: List[Dict]) -> InlineKeyboardMarkup:
    """Клавиатура для списка сессий"""
    keyboard = []
    for session in sessions:
        keyboard.append([
            InlineKeyboardButton(
                text="🔄 Переключиться",
                callback_data=f"switch_session_{session['id']}"
            ),
            InlineKeyboardButton(
                text="👁 Просмотреть",
                callback_data=f"view_session_{session['id']}"
            ),
            InlineKeyboardButton(
                text="🗑 Удалить",
                callback_data=f"delete_session_{session['id']}"
            )
        ])
    keyboard.append([
        InlineKeyboardButton(
            text="🏠 Главное меню",
            callback_data="main_menu"
        )
    ])
    return InlineKeyboardMarkup(inline_keyboard=keyboard)
```

@router.message(lambda m: m.text == "📋 Мои сессии")
async def sessions_button_handler(message: Message):
    """Обработка кнопки 'Мои сессии'"""
    # Показать список сессий с inline-кнопками
    db = await get_db()
    user = await db.ensure_user(message.from_user.id, message.from_user.username)
    sessions = await db.get_user_sessions(user["id"], limit=10)
    
    if not sessions:
        await message.answer(
            "ℹ️ У вас нет сессий.\n\n"
            "Используйте кнопку '📚 Новый запрос' для создания новой сессии.",
            reply_markup=get_main_keyboard()
        )
        return
    
    # Форматировать список сессий
    text = "📋 <b>Ваши сессии:</b>\n\n"
    # ... форматирование ...
    
    keyboard = get_sessions_keyboard(sessions)
    await message.answer(text, reply_markup=keyboard, parse_mode=ParseMode.HTML)
