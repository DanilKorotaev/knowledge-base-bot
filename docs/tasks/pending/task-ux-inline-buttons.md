# Добавление inline-кнопок для быстрых действий

**Статус**: 📋 Запланировано  
**Приоритет**: 🟡 Средний  
**Категория**: Улучшения UX

## Описание

Добавление inline-кнопок для быстрых действий без необходимости ввода команд.

## Цели

1. Добавить inline-кнопки для основных действий
2. Улучшить навигацию по истории изменений
3. Добавить быстрые действия для отката изменений
4. Добавить кнопки для управления сессиями

## Задачи

- [ ] Добавить inline-кнопки для основных действий (новый запрос, новый чат)
- [ ] Добавить inline-кнопки для навигации по истории изменений
- [ ] Добавить inline-кнопки для отката изменений
- [ ] Добавить inline-кнопки для управления сессиями
- [ ] Реализовать обработку callback-запросов
- [ ] Добавить обновление сообщений при нажатии на кнопки

## Примеры inline-кнопок

### Главное меню

```
📚 База знаний

[📝 Новый запрос] [💬 Новый чат]
[📜 История]      [🔄 Синхронизация]
[❓ Помощь]
```

### История изменений

```
📜 История изменений сессии #123

📄 file1.md - изменен
[↩️ Откатить]

📄 file2.md - создан
[↩️ Откатить]

[↩️ Откатить все] [❌ Закрыть]
```

## Связанные файлы

- `handlers/keyboards.py` - клавиатуры
- `handlers/callbacks.py` - обработка callback-запросов (нужно создать)
