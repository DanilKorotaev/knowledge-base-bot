# Улучшить логирование (структурированные логи)

**Статус**: 📋 Запланировано  
**Приоритет**: 🟡 Средний  
**Категория**: Технические улучшения

## Описание

Внедрение структурированного логирования для лучшего мониторинга и отладки.

## Цели

1. Внедрить структурированное логирование (JSON формат)
2. Добавить контекстную информацию в логи
3. Настроить разные уровни логирования для разных компонентов
4. Добавить логирование запросов и ответов

## Задачи

- [ ] Установить библиотеку для структурированного логирования (например, `structlog`)
- [ ] Настроить формат логов (JSON для продакшена, читаемый для разработки)
- [ ] Добавить контекстную информацию в логи (user_id, session_id, request_id)
- [ ] Настроить разные уровни логирования для разных компонентов
- [ ] Добавить логирование запросов к Cursor CLI
- [ ] Добавить логирование запросов к OpenAI API
- [ ] Добавить логирование операций с NextCloud
- [ ] Добавить логирование изменений файлов

## Пример структурированного лога

```json
{
  "timestamp": "2025-01-07T12:00:00Z",
  "level": "INFO",
  "component": "cursor_cli_service",
  "user_id": 123456,
  "session_id": 789,
  "message": "Обработка запроса через Cursor CLI",
  "query": "Найди информацию о системе авторасходов",
  "duration_ms": 1500
}
```

## Связанные файлы

- `bot.py` - настройка логирования
- Все сервисы - использование структурированного логирования
- `requirements.txt` - зависимости
