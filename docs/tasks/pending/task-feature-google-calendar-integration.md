## Описание

Реализация интеграции с Google Calendar API для добавления, редактирования и удаления событий через Telegram-бота. Пользователь может через бота (текстом или голосом) попросить добавить встречу, и агент распознает параметры и создаст событие в календаре.

## Цели

1. Исследовать Google Calendar API и способы интеграции
2. Реализовать аутентификацию через OAuth 2.0
3. Реализовать распознавание параметров встречи из текста (дата, время, название, местоположение, время пути)
4. Реализовать создание, редактирование и удаление событий
5. Интегрировать с агентом для обработки запросов пользователя
6. Обновить системный промпт с информацией о функциональности

## Технические детали

### Google Calendar API

- **API**: Google Calendar API v3
- **Аутентификация**: OAuth 2.0 или Service Account
- **Библиотека**: `google-api-python-client`, `google-auth`

### Пример использования

```python
from services.google_calendar_service import GoogleCalendarService

calendar = GoogleCalendarService()

# Создание события
event = calendar.create_event(
    title="Встреча с командой",
    start_time="2025-01-15T10:00:00",
    end_time="2025-01-15T11:00:00",
    location="Офис",
    description="Обсуждение проекта",
    travel_time=30  # время пути в минутах
)
```

### Примеры запросов пользователя

- "Добавь встречу на 15 января в 10:00, название 'Встреча с командой'"
- "Запланируй встречу на завтра в 14:00, местоположение 'Офис', время пути 30 минут"
- "Создай событие 'День рождения' на 20 января в 18:00"
