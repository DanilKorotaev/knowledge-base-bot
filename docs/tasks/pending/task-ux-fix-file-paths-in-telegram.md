# Задача: Исправить отображение путей к файлам в Telegram

**Статус**: 📋 Запланировано  
**Приоритет**: 🔴 Высокий  
**Категория**: Улучшения UX

## Описание

Telegram автоматически распознаёт расширение `.md` как домен верхнего уровня (Молдова) и превращает пути к файлам в кликабельные ссылки, которые никуда не ведут. Аналогично другие расширения могут интерпретироваться как домены.

## Проблема

В сообщениях об изменениях файлов:
```
📝 Изменено файлов: 2
  • Документы/Тачки/Заправки/AЗС/TEBOIL М-2 Всходы.md
  • Документы/Тачки/Соляра/Расходы/Топливо/2026-02-08 Заправка.md
```

Telegram выделяет `TEBOIL М-2 Всходы.md` и `2026-02-08 Заправка.md` как ссылки — при нажатии открывается браузер с несуществующим URL.

В ответах AI полные пути тоже могут выделяться как кликабельные — при нажатии копируются, но пользы мало.

## Решение

Обернуть пути к файлам в HTML-тег `<code>`, который гарантированно предотвращает авто-определение ссылок в Telegram.

## Задачи

- [ ] Изменить `format_file_changes_info()` в `utils/message_helpers.py`:
  - Обернуть пути в `<code>` теги: `<code>{path}</code>`
  - Экранировать HTML-символы в путях через `html.escape()`
- [ ] Убедиться, что сообщение об изменениях отправляется с `parse_mode=ParseMode.HTML`
- [ ] Добавить `link_preview_options=LinkPreviewOptions(is_disabled=True)` при отправке сообщений с путями
- [ ] Проверить, что в `handle_file_changes()` (`query_processing_service.py`) передаётся `parse_mode`

## Пример

**Было:**
```
📝 Изменено файлов: 2
  • Документы/Тачки/Заправки/AЗС/TEBOIL М-2 Всходы.md    ← ссылка!
```

**Станет:**
```
📝 Изменено файлов: 2
  • Документы/Тачки/Заправки/AЗС/TEBOIL М-2 Всходы.md    ← <code>, не ссылка
```
