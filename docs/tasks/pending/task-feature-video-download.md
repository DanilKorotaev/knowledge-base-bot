## Описание

Реализация функциональности скачивания видео из различных сервисов (YouTube, Instagram Reels, VK) и автоматической загрузки в Nextcloud. Пользователь может через бота отправить ссылку на видео, и оно будет скачано и загружено в Nextcloud с предоставлением ссылки для использования в заметках.

## Технические детали

### Библиотеки

- **yt-dlp**: Универсальная библиотека для скачивания видео с множества платформ
  - Поддержка: YouTube, Instagram, VK, TikTok и многие другие
  - Возможность выбора качества
  - Возможность скачивания только аудио

### Пример использования

```python
from services.video_download_service import VideoDownloadService

service = VideoDownloadService()

# Скачивание видео
result = service.download_video(
    url="https://www.youtube.com/watch?v=...",
    quality="best",  # или "720p", "480p", "audio"
    destination="Медиа/Видео/YouTube/"
)

# result содержит:
# - local_path: путь к скачанному файлу
# - nextcloud_path: путь в Nextcloud
# - nextcloud_link: ссылка на файл в Nextcloud
# - metadata: название, описание и т.д.
```

### Структура хранения в Nextcloud

```
Медиа/
```
