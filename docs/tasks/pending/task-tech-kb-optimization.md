## Технические детали

### Кэширование файлов

```python
from functools import lru_cache
from pathlib import Path

@lru_cache(maxsize=100)
def get_file_content_cached(file_path: str) -> str:
    """Получить содержимое файла с кэшированием"""
    return Path(file_path).read_text()
```

### Ограничение размера контекста

```python
def limit_context_size(context: str, max_tokens: int = 4000) -> str:
    """Ограничить размер контекста"""
    # Примерная оценка токенов (1 токен ≈ 4 символа)
    max_chars = max_tokens * 4
    if len(context) > max_chars:
        return context[:max_chars] + "..."
    return context
```
