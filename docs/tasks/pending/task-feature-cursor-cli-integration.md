# Интеграция с Cursor CLI

**Статус**: 📋 Запланировано  
**Приоритет**: 🔴 Высокий  
**Категория**: Новые функции

## Описание

Реализация интеграции с Cursor CLI для обработки запросов пользователей с контекстом базы знаний. Cursor CLI будет вызываться через subprocess и обрабатывать запросы с учетом системных промптов из `.cursor/rules/`.

## Цели

1. Реализовать вызов Cursor CLI через subprocess
2. Реализовать передачу запросов с контекстом базы знаний
3. Реализовать отслеживание изменений файлов (до/после выполнения)
4. Реализовать обработку ответов от Cursor CLI

## Технические детали

### Вызов Cursor CLI

```python
# Пример вызова
subprocess.run(
    ["cursor-agent", "-p", "--force"],
    cwd=kb_path,
    env={"CURSOR_API_KEY": api_key},
    timeout=300
)
```

### Отслеживание изменений

- Использовать git diff для отслеживания изменений
- Сохранять изменения в БД через change_tracker
- Возвращать список изменений вместе с ответом

## Связанные файлы
