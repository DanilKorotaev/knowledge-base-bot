# Настройка NextCloud: Сценарий с расшариванием папки

## Ваш сценарий

У вас есть:
- ✅ Админская учетка в NextCloud с папкой `KnowledgeBase` (ваша основная база знаний)
- ✅ Желание создать отдельного пользователя для бота
- ✅ Потребность в том, чтобы бот работал с **вашей** папкой, а не создавал новую

## Вариант 1: Расшаривание папки (рекомендуется)

### Как это работает

1. **Вы (админ)** создаете пользователя `telegram_knowledge_bot`
2. **Вы (админ)** расшариваете свою папку `KnowledgeBase` для пользователя бота
3. **Пользователь бота** видит расшаренную папку в своем аккаунте
4. Изменения, сделанные ботом, **отражаются в вашей папке**

### Пошаговая инструкция

#### Шаг 1: Создание пользователя для бота

1. Войдите в NextCloud как **администратор**
2. **Настройки** → **Пользователи** → **Добавить пользователя**
3. Создайте пользователя: `telegram_knowledge_bot`
4. Сохраните пароль (или создайте App Password позже)

#### Шаг 2: Расшаривание папки KnowledgeBase

1. Войдите в NextCloud как **администратор** (ваша учетка)
2. Откройте папку **KnowledgeBase**
3. Нажмите на иконку **Поделиться** (Share) рядом с папкой
4. В поле "Поделиться с пользователем или группой" введите: `telegram_knowledge_bot`
5. Выберите права доступа:
   - ✅ **Редактирование** (чтение и запись) - для работы бота
   - ❌ **Удаление** - можно отключить, если не хотите, чтобы бот удалял файлы
6. Нажмите **Поделиться**

#### Шаг 3: Проверка доступа

1. Выйдите из админской учетки
2. Войдите под пользователем `telegram_knowledge_bot`
3. Вы должны увидеть расшаренную папку **KnowledgeBase** в списке файлов
4. Папка будет отмечена как "Shared with you" (Поделено с вами)

#### Шаг 4: Создание App Password для бота

1. Войдите под пользователем `telegram_knowledge_bot`
2. **Настройки** → **Безопасность**
3. **Устройства и сессии** → **Создать новый пароль приложения**
4. Название: `Telegram Knowledge Base Bot`
5. Сохраните пароль (показывается только один раз!)

### Преимущества этого подхода

- ✅ Бот работает с **вашей** папкой, не создает дубликаты
- ✅ Все изменения видны вам сразу
- ✅ Можно контролировать права доступа (запретить удаление)
- ✅ Можно отозвать доступ в любой момент
- ✅ Безопасность: отдельный пользователь с ограниченными правами

## Вариант 2: Отдельная папка для бота (альтернатива)

Если вы хотите, чтобы у бота была **своя** папка (не расшаренная):

1. Создайте пользователя `telegram_knowledge_bot`
2. Войдите под этим пользователем
3. Создайте папку `KnowledgeBase` в его аккаунте
4. Скопируйте содержимое из вашей папки (если нужно)
5. Бот будет работать со своей копией

**Недостатки:**
- ❌ Дублирование данных
- ❌ Изменения бота не видны в вашей папке
- ❌ Нужна синхронизация между папками

## Локальная разработка на Mac

### Сценарий: Две копии на Mac

У вас будет:
- **Ваша копия**: `~/NextCloud/KnowledgeBase` (синхронизируется с вашей админской учеткой)
- **Копия бота**: `~/NextCloud-Bot/KnowledgeBase` (синхронизируется с учеткой бота)

### Настройка

#### Шаг 1: Синхронизация вашей папки (если еще не настроена)

1. Установите NextCloud клиент: `brew install --cask nextcloud`
2. Запустите клиент
3. Подключитесь к вашей админской учетке:
   - URL: `https://your-nextcloud.com`
   - Логин: ваш админский логин
   - Пароль: ваш пароль
4. Синхронизируйте папку `KnowledgeBase` → `~/NextCloud/KnowledgeBase`

#### Шаг 2: Синхронизация папки бота

1. В NextCloud клиенте добавьте **второй аккаунт**:
   - Нажмите на иконку аккаунта (вверху)
   - **Добавить аккаунт**
   - URL: `https://your-nextcloud.com`
   - Логин: `telegram_knowledge_bot`
   - Пароль: App Password, созданный ранее
2. Синхронизируйте расшаренную папку `KnowledgeBase` → `~/NextCloud-Bot/KnowledgeBase`

**Важно:** Если вы используете расшаривание (Вариант 1), то в аккаунте бота вы увидите расшаренную папку и сможете синхронизировать ее.

#### Шаг 3: Настройка Docker

1. Создайте директорию для Docker volume:
   ```bash
   mkdir -p ./local_kb
   ```

2. **Важно:** Оставьте папку пустой! Бот автоматически скачает базу знаний из NextCloud при первом запуске.

3. Настройте `.env`:
   ```bash
   LOCAL_KB_PATH=/var/knowledge-base-bot/kb
   
   # Включить автоматическую синхронизацию
   ENABLE_SYNC=true
   AUTO_SYNC=true
   SYNC_INTERVAL=300
   
   # NextCloud настройки
   NEXTCLOUD_URL=https://your-nextcloud.com
   NEXTCLOUD_BOT_USERNAME=telegram_knowledge_bot
   NEXTCLOUD_BOT_PASSWORD=your_app_password
   NEXTCLOUD_KNOWLEDGE_BASE_PATH=/KnowledgeBase
   ```

4. В `docker-compose.yml` уже настроен volume:
   ```yaml
   volumes:
     - ./local_kb:/var/knowledge-base-bot/kb
   ```

#### Шаг 4: Автоматическая синхронизация

**Бот автоматически синхронизирует изменения!**

1. **При первом запуске**: Бот скачает базу знаний из NextCloud, если папка `./local_kb/` пуста
2. **После изменений**: Бот автоматически загружает изменения в NextCloud
3. **Периодически**: Бот синхронизирует изменения из NextCloud (если `AUTO_SYNC=true`)

**Больше не нужно копировать файлы вручную!** Все происходит автоматически.

Подробнее см. [SYNC_AUTOMATIC.md](SYNC_AUTOMATIC.md)

### Структура на Mac

```
~/NextCloud/
└── KnowledgeBase/          # Ваша копия (админ)
    ├── Документация/
    ├── Templates/
    └── ...

~/NextCloud-Bot/
└── KnowledgeBase/          # Копия бота (расшаренная папка)
    ├── Документация/
    ├── Templates/
    └── ...

~/knowledge-base-bot/
├── local_kb/               # Для Docker (копия из NextCloud-Bot)
│   ├── Документация/
│   ├── Templates/
│   └── ...
└── docker-compose.yml
```

### Как это работает

1. **Бот в Docker** работает с `./local_kb/`
2. **Бот автоматически синхронизирует** изменения с NextCloud (через WebDAV API)
3. **На сервере** изменения видны в расшаренной папке
4. **Ваша папка** (админ) видит те же изменения (т.к. это одна и та же папка)
5. **NextCloud клиент** на Mac синхронизирует изменения в `~/NextCloud/KnowledgeBase/` и `~/NextCloud-Bot/KnowledgeBase/`

**Важно:** Бот синхронизируется напрямую с NextCloud через WebDAV API, не требует копирования файлов вручную!

## Часто задаваемые вопросы

### Q: Нужно ли копировать файлы вручную каждый раз?

**A:** Нет! Бот автоматически синхронизирует изменения с NextCloud через WebDAV API. При первом запуске бот скачает базу знаний из NextCloud, если папка пуста.

### Q: Как синхронизировать изменения из Docker обратно в NextCloud?

**A:** Бот делает это автоматически! Просто настройте в `.env`:
```bash
ENABLE_SYNC=true
AUTO_SYNC=true
```
После каждого изменения бот автоматически загрузит изменения в NextCloud.

### Q: Можно ли использовать одну папку для обоих аккаунтов?

**A:** Технически можно, но не рекомендуется:
- Могут быть конфликты синхронизации
- Сложнее отслеживать, кто что изменил
- Лучше иметь отдельные локальные копии

### Q: Что если я хочу, чтобы бот работал только с частью файлов?

**A:** Можно:
1. Создать подпапку в `KnowledgeBase` (например, `KnowledgeBase/Bot/`)
2. Расшарить только эту подпапку для бота
3. Бот будет видеть только эту часть
