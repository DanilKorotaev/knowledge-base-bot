         │
         ▼

         │

## Компоненты

### 1. Telegram Bot (aiogram)
- Обработка сообщений от пользователей
- Управление сессиями
- Отправка ответов

### 2. Cursor CLI Service
- Вызов Cursor CLI через subprocess
- Обработка запросов с контекстом базы знаний
- Отслеживание изменений файлов

### 3. Database Layer
- PostgreSQL для продакшена
- SQLite для локальной разработки
- Абстракция через DatabaseInterface

### 4. NextCloud Integration
- Синхронизация локальной копии с NextCloud
- WebDAV API для работы с файлами

### 5. OpenAI Service
- Транскрибация голосовых через Whisper API

## Поток данных

1. Пользователь отправляет запрос в Telegram
2. Бот создает/обновляет сессию в БД
3. Бот вызывает Cursor CLI с запросом
4. Cursor CLI обрабатывает запрос с контекстом БЗ
5. Бот получает ответ и список изменений
6. Бот сохраняет изменения в БД
7. Бот синхронизирует изменения с NextCloud
8. Бот отправляет ответ пользователю
